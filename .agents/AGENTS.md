# Project Rules for Nutralab VLC

- Todos los modales y drawers tienen que ser ResponsiveModal (Modal en escritorio / Drawer Bottom Sheet en móvil) utilizar componente ya creado en modals/ResponsiveModal.jsx y se pone en la carpeta modals

- Si vas a usar el icono de nutralab usa el de la carpeta components/Icon3D

- **UI & Badges Directive**: Do NOT use Badges (`<Badge>`) in the player list or team dashboard tables. Use clean, elegant typographic layouts, subtle status dots/indicators (`●`), and crisp font hierarchy instead.

- Cada cambio que hagas en la aplicacion antes de quitar hacer el npm run lint y npm run build
